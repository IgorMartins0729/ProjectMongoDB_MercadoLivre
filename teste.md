EX2.pdf: O documento de requisitos da disciplina de Banco de Dados Não Relacional. Ele define o objetivo do trabalho: implementar as funções de Insert, Update, Search e Delete para todas as três coleções (usuário, vendedor e produto) do Mercado Livre no MongoDB.  menu.py: O arquivo principal do projeto. Ele já possui um menu interativo funcional e toda a estrutura de operações CRUD pronta para a coleção de usuários. É nele que você vai trabalhar, duplicando e adaptando essa lógica para as outras coleções.  mymongo.py: Um script de teste que você acabou de usar. Ele serve exclusivamente para guardar a sua string de conexão (uri) e rodar operações básicas para garantir que o Python consegue conversar com o seu cluster online do MongoDB.  objeto.py: Um arquivo de exemplo para demonstrar como o Python lida com estruturas de dados complexas. Ele mostra como usar um laço while para cadastrar vários endereços em uma lista, criptografar senhas com a biblioteca hashlib e usar o módulo json para transformar textos em dicionários e vice-versa.  objetos.py: Um script de estudo quase idêntico ao objeto.py. Ele ilustra passo a passo como coletar dados do terminal via input, criptografar a senha e montar um objeto final estruturado, semelhante ao formato que o MongoDB espera receber.  obj-json.py: Um pequeno script técnico focado nas funções json.loads() (que transforma uma string JSON em um objeto manipulável no Python) e json.dumps() (que converte o objeto de volta para string). Serve apenas como material de consulta rápida.
